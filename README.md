# 🛡️ AI Phishing Detector - Cyber Shield

An AI-powered phishing URL detection system that detects suspicious links and classifies them as Safe or Phishing.

## 🚀 Features

- 🔍 AI-based URL detection
- ⚠️ Phishing link identification
- 📊 Risk score analysis
- 🔎 Suspicious keyword detection
- 🌐 Web-based user interface
- 🛡️ Cyber Shield protection

## 🛠️ Technologies Used

- Python
- Flask
- Machine Learning
- Scikit-learn
- Pandas
- Joblib
- HTML
- CSS
